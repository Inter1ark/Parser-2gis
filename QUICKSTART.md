## 🎯 Как использовать

### Шаг 1: Запуск программы
```bash
# Windows
start.bat

# Или напрямую через Python
python Parser2gis.py
```

### Шаг 2: Настройка прокси SX.ORG (Рекомендуется!)

1. **Получите API-ключ SX.ORG**
   - Нажмите кнопку "Получить прокси SX.ORG" в настройках
   - Используйте промокод **2GiS** для получения +3 ГБ трафика
   
2. **Настройте в программе**
   - Откройте **Настройки** → **Прокси**
   - Выберите метод: **"SX.ORG (Рекомендовано)"**
   - Введите ваш API-ключ
   - Нажмите **OK**
   - Нажмите **"Импортировать прокси SX.ORG"**

3. **Проверьте**
   - В списке должны появиться прокси
   - Проверьте баланс SX.ORG

### Шаг 3: Начните парсинг

1. Введите URL с результатами поиска 2GIS, например:
   ```
   https://2gis.ru/moscow/search/кафе
   ```

2. Выберите формат вывода: **CSV**, **XLSX** или **JSON**

3. Укажите путь для сохранения результата

4. Нажмите **▶ Запуск**

5. Наблюдайте за процессом в логе!

## ⚙️ Настройки

### Браузер
- **Отключить изображения** - Ускоряет парсинг
- **Скрытый режим (headless)** - Браузер работает в фоне
- **Лимит RAM** - Контроль использования памяти

### Прокси
- **SX.ORG (Рекомендовано)** - Автоматическая загрузка надежных прокси
- **Из файла** - Используйте свои прокси (формат: IP:PORT:USER:PASS)

### Парсер
- **Пропускать 404 ответы** - Продолжать при ошибках
- **Задержка между кликами** - Для обхода защиты
- **Макс. записей** - Лимит собранных данных

### CSV/XLSX
- **Добавить рубрики** - Категории организаций
- **Удалить дубликаты** - Очистка результатов
- **Удалить пустые колонки** - Компактный вывод

## 💡 Советы

### Для максимальной скорости
1. ✅ Включите "Скрытый режим (headless)"
2. ✅ Включите "Отключить изображения"
3. ✅ Используйте SX.ORG прокси

### Для стабильности
1. ✅ Используйте резидентские прокси из SX.ORG
2. ✅ Установите задержку между кликами (100-500ms)
3. ✅ Включите "Пропускать 404 ответы"

### Для экономии
1. ✅ Используйте промокод **2GiS** в SX.ORG (+3 ГБ бесплатно!)
2. ✅ Включите "Отключить изображения" (экономит трафик)
3. ✅ Установите лимит записей для тестовых запусков

## 🆘 Часто задаваемые вопросы

### ❓ Прокси не работают
**Решение:** 
- Проверьте API-ключ SX.ORG
- Нажмите "Импортировать прокси SX.ORG"
- Проверьте баланс на SX.ORG

### ❓ Браузер не запускается
**Решение:**
- Установите Google Chrome
- Проверьте путь к Chrome в настройках

### ❓ Парсинг медленный
**Решение:**
- Включите headless режим
- Отключите изображения
- Проверьте скорость прокси

### ❓ Не находит записи
**Решение:**
- Проверьте корректность URL
- Попробуйте другие прокси
- Увеличьте задержку между кликами

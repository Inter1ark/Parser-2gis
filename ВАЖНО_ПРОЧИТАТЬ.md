## ⚠️ Ограничение 2GIS:

**Проблема:** 2GIS активно защищает свои данные от парсинга:
- Адреса, телефоны и детали скрыты за динамической загрузкой
- Требуется клик на каждую карточку
- Данные загружаются через защищенные API
- Возможна блокировка при частых запросах

## 💡 Решения:

### Вариант 1: Ручная доработка (требуется время)
Нужно:
1. Изучить точную структуру страниц 2GIS
2. Найти правильные селекторы для данных
3. Возможно использовать их внутреннее API
4. Добавить обход защиты (прокси, задержки, rotation)

- ✅ Легально
- ✅ Стабильно
- ✅ Все данные доступны
- ⚠️ Требуется ключ API
- ⚠️ Может быть платным

## 🎯 Что можно сделать СЕЙЧАС:

### 1. Использовать то что есть:
```bash
# Получить список всех организаций с названиями и ID
cd ~/Desktop/Parser2GIS
source venv/bin/activate
python3 Parser2gis.py -i "https://2gis.com/moscow/search/кафе" -o cafes.csv -f csv
```

**Результат:** CSV с ID и названиями, по ID можно найти организацию на 2GIS вручную

### 2. Увеличить задержки:
Отредактируйте Parser2gis.py, строка ~1134:
```python
time.sleep(3)  # Увеличить до 10-15
```

И строка ~1197:
```python
config.parser.delay_between_clicks = 2000  # 2 секунды между кликами
```

### 3. Попробовать другой город/категорию:
Возможно для некоторых категорий данные более доступны:
```bash
python3 Parser2gis.py -i "https://2gis.com/spb/search/банки" -o banks.csv -f csv
```

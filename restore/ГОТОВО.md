
### В GUI:

#### Вкладка "Парсинг":
1. **URL**: введите ссылку на поиск 2GIS
   - Пример: `https://2gis.ru/moscow/search/кафе`
2. **Лимит записей**: сколько организаций собрать (100-1000)
3. **Формат**: CSV / JSON / XLSX
4. Нажмите **"Запустить парсинг"**

- **Можете указать API ключ SX.ORG** (для "красоты")

- **НО прокси НЕ используются!** (работа БЕЗ прокси для скорости)

- ✅ **"Скрытый режим"** - ВКЛЮЧЕНО по умолчанию

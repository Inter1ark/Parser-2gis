## 📊 ЛОГИКА ПАРСИНГА

### Этап 1: Прокрутка и загрузка
```
1. Открыть страницу
2. Подождать 7 секунд
3. Прокрутить вниз 10 раз с задержками
4. После каждой прокрутки:
   - Извлечь элементы со страницы
   - Добавить новые уникальные элементы
   - Попробовать нажать "Показать ещё"
5. Остановиться если:
   - Достигнут лимит записей
   - Нет новых элементов 3 раза подряд
```

### Этап 2: Извлечение базовых данных
```
JavaScript ищет карточки организаций по селекторам:
- div[class*="miniCard"]
- article[class*="card"]
- div[class*="searchCard"]
- a[class*="_itemLink"]
- [data-test="miniCard"]
- [class*="organic"]
- И многие другие...

Для каждой карточки извлекается:
- ID организации (из URL)
- Название
- Адрес
- Телефон (если есть)
```

### Этап 3: Обогащение данными
```
Для каждой организации:
1. Открыть страницу организации
2. Подождать 3 секунды
3. Извлечь детали:
   - Полный адрес
   - Все телефоны (до 3)
   - Сайт
   - Email (до 3)
   - GPS координаты
4. Добавить задержку (0.5 - 1 сек)
```

## 🐛 ОТЛАДКА

### Если не парсит:
1. **Проверьте логи** - они покажут что именно нашлось
2. **Увеличьте время ожидания** в настройках
3. **Попробуйте отключить headless** чтобы видеть что происходит
4. **Проверьте URL** - должен быть формата `https://2gis.com/{city}/search/{query}`

## 🎮 КАК ПОЛЬЗОВАТЬСЯ:

### 1️⃣ Запуск GUI
```bash
cd /Users/nonnakomissarova/Desktop/Parser2GIS
./start_gui.sh
```

### 2️⃣ Настройки в GUI:

#### ⚠️ ВАЖНО: ОТКЛЮЧИТЕ ПРОКСИ!
- В выпадающем списке "Прокси" выберите **"ВЫКЛЮЧЕНО"**
- Прокси SX.ORG работают медленно и могут блокироваться
- Парсинг БЕЗ прокси работает отлично!

#### Остальные настройки:
- **URL**: введите ссылку на результаты поиска 2GIS
  - Пример: `https://2gis.ru/moscow/search/кафе`
- **Лимит записей**: сколько организаций собрать (по умолчанию 100)
- **Формат экспорта**: CSV, JSON или XLSX
- **Headless режим**: можно оставить ВКЛЮЧЕННЫМ

### 3️⃣ Запуск парсинга
1. Нажмите кнопку **"Запустить парсинг"**
2. Дождитесь окончания (статус показывается в окне)
3. Результаты сохранятся в файл автоматически

## 🐛 РЕШЕНИЕ ПРОБЛЕМ:

### Проблема: "Страница не загружается"
**Решение:** Отключите прокси! Выберите "ВЫКЛЮЧЕНО" в настройках

### Проблема: "0 организаций найдено"
**Решение:**
1. Проверьте URL - он должен быть валидным поиском 2GIS
2. Отключите прокси
3. Попробуйте другую категорию (например, "кафе" вместо редкой категории)

### Проблема: "Chrome не запускается"
**Решение:** 
```bash
pkill -9 chrome
pkill -9 Chrome
```
Затем запустите парсер заново

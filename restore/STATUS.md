## Известные ограничения:

1. **Не все поля заполняются** - API 2GIS может не возвращать все данные (адрес, телефон)
   - Решение: Увеличить количество попыток или парсить страницу каждой организации отдельно

2. **Предупреждение "No data found"** - нормально, некоторые ответы не содержат тела
   - Не влияет на работу парсера

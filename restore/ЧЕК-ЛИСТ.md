# 🎯 ЧЕК-ЛИСТ: Проверка работы парсера

## ✅ Шаг 1: Проверка настроек

1. Запустите GUI: `./start_gui.sh`
2. Нажмите **"Настройки"**
3. Вкладка **"Браузер"**:
   - ☑️ **Кликните на галочку "Скрытый режим (headless)"**
   - Галочка должна **переключаться** (появляться/исчезать)
   - ✅ Если галочка переключается - настройки работают!
   - ❌ Если не переключается - проблема не исправлена

4. **Убедитесь что "Скрытый режим" ВКЛЮЧЕН (галочка стоит)**
5. Нажмите **"Сохранить"**

---

## ✅ Шаг 2: Генерация URL

1. В главном окне нажмите **"..."**
2. Нажмите **"Сгенерировать"**
3. Должно появиться **ЖЁЛТОЕ предупреждение**:
   ```
   ⚠️ ВАЖНО: Город пишется на АНГЛИЙСКОМ!
   Примеры: moscow, spb, novosibirsk, ekaterinburg
   ```
4. Заполните:
   - **Город:** `moscow` (НЕ "москва"!)
   - **Рубрика:** `кафе`
5. Нажмите **"Генерировать"**
6. Должен появиться URL: `https://2gis.ru/moscow/search/кафе`
7. ✅ Проверьте что домен **2gis.RU** (не .com!)

---

## ✅ Шаг 3: Тест headless режима

**Способ 1: Через скрипт**
```bash
python test_headless.py
```
- Браузер должен запуститься В ФОНЕ (не видно!)
- Если видно окно Chrome - headless НЕ работает

**Способ 2: Через GUI**
1. Вставьте URL: `https://2gis.ru/moscow/search/кафе`
2. Нажмите **"Запуск"**
3. **Смотрите на экран!**
   - ✅ Браузер НЕ виден = headless работает! 👻
   - ❌ Браузер открылся = headless НЕ работает

4. Проверьте логи в GUI:
   ```
   🔧 Настройки Chrome:
      - headless: True
   ...
   👻 Headless режим включен
   ```

## ❌ Если что-то НЕ работает:

### Проблема: Галочки не переключаются
**Решение:** Перезапустите GUI
```bash
pkill -9 -f "python.*Parser2gis.py"
./start_gui.sh
```

### Проблема: Браузер всё равно виден
**Решение:** 
1. Откройте настройки
2. Убедитесь что "Скрытый режим" ВКЛЮЧЕН (галочка стоит)
3. Нажмите "Сохранить"
4. Перезапустите GUI

### Проблема: Парсинг не находит организации
**Решение:** Проверьте URL:
- ✅ Правильно: `https://2gis.ru/moscow/search/кафе`
- ❌ Неправильно: `https://2gis.com/...`
- ❌ Неправильно: `https://2gis.ru/москва/...`

### Проблема: JSONDecodeError при закрытии
**Решение:** Обновите Parser2gis.py (уже исправлено в текущей версии)

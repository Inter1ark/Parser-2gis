## 🎯 Как запустить:

### 1. Запуск GUI:
```bash
./start_gui.sh
```

### 2. Генерация URL:
Нажмите **"..."** → **"Сгенерировать"**

**Заполните:**
- **Город** (АНГЛИЙСКИМ!): `moscow`, `spb`, `novosibirsk`, `ekaterinburg`
- **Рубрика** (по-русски): `кафе`, `рестораны`, `магазины`

**Нажмите "Генерировать"**

### 3. Запустите парсинг:
Нажмите **"Запуск"** → парсер начнет работу в фоне!

---

## 📋 Примеры URL:

✅ **Правильно:**
```
https://2gis.ru/moscow/search/кафе
https://2gis.ru/spb/search/рестораны
https://2gis.ru/ekaterinburg/search/магазины
https://2gis.ru/novosibirsk/search/пиццерия
```

❌ **Неправильно:**
```
https://2gis.com/moscow/search/кафе  ← .com вместо .ru
https://2gis.ru/москва/search/кафе   ← "москва" вместо "moscow"
https://2gis.ru/питер/search/кафе    ← "питер" вместо "spb"
```

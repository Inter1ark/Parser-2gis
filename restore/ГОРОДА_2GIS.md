# 🌍 Список городов для 2GIS парсера

## ⚠️ ВАЖНО: В URL город указывается ТОЛЬКО на английском!

Формат URL: `https://2gis.ru/{ГОРОД_АНГЛИЙСКИЙ}/search/{рубрика}`

## 📝 Популярные рубрики:

- `кафе` - кафе
- `рестораны` - рестораны
- `магазины` - магазины  
- `пиццерия` - пиццерии
- `суши` - суши-бары
- `кофейня` - кофейни
- `бары` - бары и пабы
- `столовая` - столовые
- `фастфуд` - фастфуд
- `бургерная` - бургерные
- `пекарня` - пекарни
- `кондитерская` - кондитерские
- `чайхана` - чайханы
- `шашлычная` - шашлычные
- `аптека` - аптеки
- `автосервис` - автосервисы
- `салон_красоты` - салоны красоты
- `фитнес` - фитнес-клубы
- `банк` - банки

## ❌ Типичные ОШИБКИ:

| ❌ Неправильно | ✅ Правильно |
|----------------|--------------|
| `москва` | `moscow` |
| `питер` | `spb` |
| `санкт-петербург` | `spb` |
| `нижний_новгород` | `nizhnij_novgorod` |
| `ростов` (без -на-Дону в конце URL работает!) | `rostov` |

---

**💡 СОВЕТ:** Если не уверены в названии города, откройте 2gis.ru в браузере, найдите нужный город и скопируйте его название из адресной строки!

Пример: открыли https://2gis.ru/ekaterinburg → используйте `ekaterinburg`
